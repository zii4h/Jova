# AI Usage

This document records how AI was used during the development of Jova and will be updated throughout the remaining development period.

## 1. How I Used AI

AI was used as guidance while implementing several parts of Jova, including:

- Setting up Google OAuth login with Supabase Authentication.
- Setting up the Supabase database for persistent, per-user application data.
- Implementing Gemini-powered Field Analysis through a Supabase Edge Function so the Gemini API key remains on the server side.

AI was mainly used to guide the implementation, explain unfamiliar configurations, and help troubleshoot issues encountered during development.
